# Security and safety reports

Please use a private GitHub security advisory for vulnerabilities that
could expose local data, bypass the read-only command boundary, or cause
unsafe serial behavior. Do not attach unredacted battery evidence to a
public issue.

For ordinary compatibility problems and documentation corrections, use
a public issue after removing serial numbers, local paths, and
installation details.

This project cannot provide emergency electrical or battery support.
For heat, odor, swelling, smoke, arcing, damaged wiring, or other signs
of a battery hazard, stop interacting with the equipment and follow the
manufacturer's emergency procedure.
